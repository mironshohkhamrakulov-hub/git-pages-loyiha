## 📌 Loyiha haqida

Bu — **GitHub Pages** xizmati qanday ishlashini amalda o'rganish uchun yaratilgan sodda mashq loyihasi. Loyiha orqali statik HTML sahifani GitHub orqali internetga joylashtirish (deploy qilish) jarayoni o'rganilmoqda.

Sahifada quyidagilar mavjud:
- 👋 Salomlashuv sarlavhasi (`<h1>`)
- 📝 Loyiha haqida qisqa izoh (`<p>`)
- 🔘 Interaktiv tugma (`<button>`)

## ⚙️ O'rnatish va ishga tushirish

1. Repositoriyani klonlang:
   ```bash
   git clone https://github.com/mironshohkhamrakulov-hub/git-pages-loyiha.git
   ```
2. `index.html` faylini brauzerda oching — tayyor! 🎉
